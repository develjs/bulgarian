Создай полноценное SPA-приложение для изучения болгарского языка (уровень А1–А2) на React в виде ОДНОГО самодостаточного HTML-файла. Приложение должно открываться прямо в браузере без сервера и без сборки.

СТЕК:
- React 18 + ReactDOM через CDN (UMD-сборки, production.min.js)
- Babel Standalone через CDN для JSX прямо в браузере (<script type="text/babel">)
- НЕ использовать Tailwind CDN. Все стили — обычный CSS в теге <style> внутри того же файла, реализующий тот же визуальный стиль: мягкий градиентный фон от голубого к индиго, светлые карточки с тенями, скруглённые углы, инпуты с цветными рамками.
- Один HTML-файл, всё встроено (никаких отдельных .js/.css файлов).

ТЕМА: сложноподчинённые предложения первого типа (реальное условие) в болгарском языке с союзами: ако, когато, щом, докато.

СТРУКТУРА: 6 упражнений по 6 предложений = 36 заданий всего.
1. Упражнение 1 — вставить глагол в правильную форму (в главном предложении после "ще", перфектный вид)
2. Упражнение 2 — сделать предложение отрицательным (в придаточном после союза, "не" + форма без "ще")
3. Упражнение 3 — сделать предложение вопросительным (частица "ли" после глагола, без изменения порядка слов)
4. Упражнение 4 — выбрать союз (ако/когато/щом/докато) из выпадающего списка
5. Упражнение 5 — перевести предложение с русского на болгарский целиком
6. Упражнение 6 — микс всех типов (2 input, 2 select, 2 translate)

КРИТИЧЕСКИ ВАЖНО про упражнение 4 (и select-пункты в упражнении 6): каждое предложение должно быть построено так, чтобы по смыслу подходил ТОЛЬКО ОДИН союз, а не несколько взаимозаменяемых. Не делай предложений, где годятся 2-3 варианта.

ФУНКЦИОНАЛ:
- Стартовая страница — сразу первое упражнение, без меню.
- Поле ввода/выпадающий список встроены inline в текст предложения (не отдельной строкой).
- Подсказка в скобках после предложения (только для input-упражнений) — глагол БЕЗ местоимения, например "(помагам)", а не "(аз помагам)".
- У каждого предложения — своя кнопка "Провери". В конце страницы — кнопка "Провери всичко" (проверяет все непроверенные).
- После проверки поле блокируется (редактирование недоступно), кнопка "Провери" скрывается.
- Визуальная обратная связь: правильный ответ — зелёная рамка + ✓; близкий ответ (ошибка ≤30% длины строки без пробелов/знаков, по расстоянию Левенштейна) — жёлтая рамка + ⚠; неправильный — красная рамка + ✗ и лёгкая анимация "тряски" карточки.
- Проверка ответа: игнорировать регистр, пробелы и знаки пунктуации; сравнение через расстояние Левенштейна.
- Строка "Правилен отговор: <верный вариант>" показывается ТОЛЬКО когда ответ неверный или близкий (не когда правильный).
- Под каждым проверенным заданием (независимо от того, правильно оно или нет) ВСЕГДА дополнительно показывается короткое грамматическое объяснение (с иконкой 💡) — одно и то же для всех, кто бы что ни ввёл: почему именно такая форма/союз/конструкция, а не другая. Текст объяснения для каждого из 36 предложений — см. ниже, бери готовый.
- Случайный комментарий на болгарском под каждым проверенным заданием:
  correct (10 вариантов): "Отлично!", "Перфектно!", "Браво!", "Супер!", "Точно така!", "Много добре!", "Великолепно!", "Ти си звезда!", "Продължавай така!", "Чудесно!"

  (НЕ используй "Опитай отново!" — приложение не даёт повторную попытку сразу, эта фраза сбивает с толку.)
- Прогресс-бар в шапке страницы, общий на все 36 заданий: "X / 36", заполняется по мере правильных ответов (только полностью правильные засчитываются в счёт).
- Навигация: "← Назад" (со 2-й страницы), "Следващо упражнение →" (появляется только когда все 6 заданий на странице проверены), на последней странице кнопка "Завърши →".
- Финальная страница: эмодзи по результату (≥90% — 🏆, ≥75% — 🌟, ≥60% — 👍, <60% — 💪), счёт "X / 36", процент, кнопка "Започни отново" (полный сброс состояния).
- При переходе между упражнениями состояние страницы не должно "утекать" — используй React state, поднятый в родительский компонент (не reset через remount, если это ломает подсчёт очков).
- Никакого localStorage/sessionStorage — только React state в памяти.
