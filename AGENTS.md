# Учим български — правила для агента

Одностраничное SPA для болгарского A1–A2: сложноподчинённые предложения с союзами ако, когато, щом, докато и глаголы движения. Пользователь пишет по-русски. Интерфейс приложения — на болгарском.

## Жёсткие ограничения

- Обычное Node-приложение на Vite. Зависимости в `package.json`. Запуск: `npm install`, затем `npm run dev`. Сборка: `npm run build` кладёт сайт в `docs/` (так GitHub Pages отдаёт папку с ветки). `docs/` не в `.gitignore`, её коммитят. `base` в Vite — `./`. Не возвращать Babel Standalone, CDN-скрипты React и `type="text/babel"`. Не переименовывать выход обратно в `dist/`.
- Сборка должна открываться двойным щелчком по `docs/index.html` (`file://`). Поэтому выход — один IIFE-скрипт без `type="module"` и без атрибута `crossorigin` на скрипте и стилях. Иначе Chrome блокирует загрузку с диска.
- Исходники в `src/`: `main.jsx` монтирует приложение, `App.jsx` — экраны, `components/` — JSX-компоненты, `data/tests.js` — список видов тестов и карта модулей, `data/<id>.js` — только массив `EXERCISES` этого теста (`data/uslovie-tip-1.js`, `data/glagoli-za-dvizhenie.js`), `lib/` — проверка ответа, комментарии и `testContent.js` (`prepareTest`: разворот строк, `TOTAL_ITEMS`, `makeEmptyAllState`), `styles.css` — стили. Связь между файлами только через `import` / `export`, не через `window`.
- JSX остаётся JSX. Транспиляцию делает `@vitejs/plugin-react` при `dev` и `build`.
- Tailwind не подключать. Стили только в `src/styles.css`: градиент от голубого к индиго, светлые карточки с тенью, скругления, цветные рамки полей.
- Никакого `localStorage` / `sessionStorage`. Состояние только в React, в памяти.
- Тексты заданий брать как есть из частей 2 и 3 `instructions.md` и массива `EXERCISES` соответствующего теста. Часть 1 — описание интерфейса, её не трогать, когда меняются упражнения. Не придумывать новые предложения и не переписывать эталоны, подсказки и объяснения, пока пользователь явно этого не попросит.
- В тесте `uslovie-tip-1` в упражнении 4 и в select-пунктах упражнения 6 по смыслу подходит ровно один союз. В тесте `glagoli-za-dvizhenie` подсказок `[…]` нет. Упражнение 5 — перевод в поле, без списка. Остальные пункты — `select`. В упражнении 4 и в трёх пунктах упражнения 6 подходит ровно один предлог. У «Выхожу из дома в семь» засчитаны два перевода.

## Карта кода

- `EXERCISES` каждого теста — 6 упражнений × 6 заданий. Типы: `input` (пропуск в строке), `select` (союз или предлог в строке), `translate` (русская фраза + поле на весь перевод).
- Фраза пункта — одна строка `text`. Эталоны: `{ответ1|ответ2}`. Подсказка: `[глагол]`, в конце или рядом с переводом. Пропуск внутри фразы — поле того же типа, что и остальные пропуски этой строки. `{…}` после законченного предложения — перевод, отдельное поле под фразой. При загрузке строка режется на части и `blanks`. Пробелы снаружи пропуска остаются на экране. `options` у выбора союза — отдельное поле. Карточка верна, когда верны все её поля. Счёт по-прежнему один пункт на карточку.
- `TESTS` в `data/tests.js` — список видов тестов. Два: id `uslovie-tip-1`, название «Сложноподчинени изречения (условие тип 1)», и id `glagoli-za-dvizhenie`, название «Глаголи за движение». Задания лежат в `data/<id>.js`. `TEST_CONTENT` сопоставляет id с `prepareTest(EXERCISES)` модуля. Название и строку итога не дублировать в JSX: начальная страница, подвал и финал читают их из `TESTS`.
- При открытии `activeTestId` равен `null`: видна `HomePage` с приглашением и кнопкой «Започни» у каждого теста. Шапка с прогрессом скрыта. «Започни» ставит `activeTestId`, обнуляет ответы и открывает упражнение 0.
- Дальше `App` хранит `pageIndex` (0–5, 6 = финал) и `allState`. `ExercisePage` пересоздаётся через `key={pageIndex}`, но ответы живут в родителе и при «Назад» не сбрасываются. Подвал: «Учене на български език · {title}».
- `evaluateAnswer`: нижний регистр, без пунктуации и лишних пробелов; иначе Левенштейн по строке без пробелов. Доля правок ≤ 30% длины эталона — `close`, иначе `wrong`. Пустой ввод — `wrong`.
- В прогресс «X / 36» входят только `checked && result === "correct"`. `TOTAL_ITEMS` считается из данных и равен 36.
- После проверки поле блокируется, кнопка «Провери» скрывается. «Правилен отговор» — только при `close` и `wrong`. Пояснение с 💡 — всегда, один и тот же текст. Комментарий на болгарском случайный, из трёх списков по 10 фраз. Фразы «Опитай отново!» нет: повторной попытки нет.
- «Провери всичко» проверяет только ещё не проверенные. «Следващо упражнение →» появляется, когда проверены все 6 на странице; на последней — «Завърши →». «← Назад» со 2-й страницы.
- Финал: 🏆 ≥ 90%, 🌟 ≥ 75%, 👍 ≥ 60%, иначе 💪. «Започни отново» вызывает `makeEmptyAllState()` и `pageIndex = 0`, тест не закрывает и на начальную страницу не возвращает.

## Как менять и проверять

- Проверка: `npm run dev`, затем сценарий в браузере: ввод, «Провери», близкий ответ, «Провери всичко», переход вперёд и назад, финал, перезапуск. Перед сдачей правки имеет смысл прогнать `npm run build`.
- Тёмная тема следует `prefers-color-scheme`; переключателя нет. Фоны верно/близко/неверно остаются светлыми — на них легко потерять контраст текста.
- Спека интерфейса — часть 1 `instructions.md`, контент заданий — части 2 и 3. При расхождении кода и спеки не молча переписывай эталоны: сверься с пользователем, если правка меняет учебный ответ.
